# Bhagavatham AI Agent

A production-style Retrieval-Augmented Generation (RAG) application for the Śrīmad Bhāgavatam.

## Features

- Semantic search
- ChromaDB vector store
- AI Agent
- MCP tools
- Streamlit interface
- Grounded answers with citations

## Tech Stack

- Python
- Streamlit
- ChromaDB
- Sentence Transformers
- FastMCP
- Hugging Face
